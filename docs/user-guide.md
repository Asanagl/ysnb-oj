# YSNB OJ 选手使用手册

> 适用对象：ACM 队全体成员。网址：`http://<your-server-ip>/`（校内网访问）。

## 一、注册与登录

1. 向管理员要一个**邀请码**（每个邀请码有使用次数上限）。
2. 首页点击「注册」，填写用户名、密码、昵称、学号和邀请码。
3. 登录后右上角点头像可修改资料、查看个人主页。

> 忘记密码找管理员重置；多次输错密码会触发限流（每分钟 10 次），稍等再试。

## 二、刷题

- 「题库」里浏览所有可见题目，可按标题搜索、按标签筛选。
- 点进题目：题面支持 LaTeX 公式渲染，下方有样例。
- 点「提交」写代码（或直接粘贴），选择语言后提交。语言与档位：

| 语言 | 时限倍率 | 内存放宽 |
|---|---|---|
| C++ 17 | 1× | +8 MB |
| Python 3 | 4× | +128 MB |
| Java 17 | 3× | +256 MB（JVM 参数已配好） |

- 判题状态实时推送，无需刷新页面。结果含义：

| 结果 | 含义 |
|---|---|
| AC | 通过 |
| WA | 答案错误（对比标准输出，或被 SPJ 判错） |
| TLE | 超出时限（含语言倍率后仍超时） |
| MLE | 超出内存 |
| RE | 运行时错误（崩溃、非零退出码） |
| CE | 编译错误（会显示编译器报错） |
| SE | 判题系统错误（不是你的问题，找管理员） |

- 提交后可回看自己的代码与每个测试点的用时/内存。
- 每用户每分钟最多提交 15 次。
- **比赛内提交**（不含补题）采用「首败即停」：一旦某个测试点不通过，
  后面的测试点直接标记 `SKIPPED` 跳过，不继续跑——比赛里你只需要知道
  过没过，这样也把判题资源让给其他选手；平时训练提交始终跑完全部测试点，
  帮你定位到底哪几个点有问题。

## 三、题解区

- 题目页有「题解」楼层：**你对该题提交过（任意结果）后才能查看与发帖**；
  比赛进行中的赛题题解全区锁定，比赛结束自动开放。
- 支持回复楼层；题目作者与管理员可发「官方题解」（置顶标识）。

## 四、训练题单

- 「题单」页面是全站公开的训练列表。
- 每道题自动显示你的进度：**未做 / 已尝试 / 已 AC**。
- 小组成员还能在小组页看到队长共享的题单。

## 五、比赛

- 「比赛」列表查看进行中/ upcoming 比赛。**报名制比赛必须先在比赛页点报名**，
  否则无法提交。
- ACM 赛制：罚时按分钟计、实时榜单、封榜后冻结（比赛页顶部会提示）。
- **组队赛（ICPC 三人一队）**：比赛开启组队模式时，报名页改为「以队报名」——
  选一个你担任**队长**的小组报名即可，全队共享成绩；任一队员提交即队伍提交；
  榜单按队伍聚合显示。
- 比赛结束后进入补题模式：提交不再影响榜单，题解区自动开放。

## 六、训练小组

- 「小组」页面可创建小组（建队者即队长，人数上限默认 3 人，可配 1–5）。
- 加入方式两种：队长在小组页**直接拉人**（搜索用户名/昵称），或把**邀请码**
  发给同学自行加入。
- 队长可以：拉人/踢人/转让队长/重置邀请码/发公告/共享题单。
- 小组页有**队内排行**（按组内共享题单的去重 AC 数排序）。

## 七、个人主页

- 顶部统计：总提交数、AC 数、AC 率等。
- 提交记录可按题目、状态筛选，点开回看代码。

## 八、常见问题

| 现象 | 处理 |
|---|---|
| 提交一直 PENDING | 判题机可能在忙（多人同时提交），等一会；持续超过 5 分钟找管理员 |
| 交互题怎么交互 | 程序的 stdin/stdout 直连判题机 interactor，读到什么答什么 |
| 注册码失效 | 邀请码有次数/有效期限制，找管理员要新的 |
| 网页上不去 | 校内网问题或服务器维护，找管理员 |
