# YSNB OJ 选手手册

> 读者对象：ACM 队选手与所有普通用户。在浏览器打开站点地址即可使用，界面为全中文，支持明暗双主题。

## 界面速览

顶部导航栏：**首页 / 题库 / 提交记录 / 比赛 / 题单 / 小组 / 个人中心**（管理员另有「后台管理」入口）。导航栏右侧的图标按钮可切换主题：**浅色 / 暗色 / 跟随系统**。手机等窄屏设备上，导航收进左上角的抽屉菜单。

「首页」是你的个人仪表盘：左侧「我的统计」（已解决题目数与各判定状态计数），右侧「我最近的提交」。

## 我想注册和登录

1. 先向管理员要一个**邀请码**（有使用次数和有效期限制）。
2. 打开站点地址，在登录页切到「注册」标签，填写：用户名（3–32 位）、昵称（可选）、学号（必填）、密码（至少 6 位）、邀请码。
3. 提示「注册成功，请登录」后切回「登录」标签，用用户名和密码登录。

忘记密码找管理员重置。登录接口限流为每分钟 10 次，连续输错请稍等再试。

## 我想刷题

1. 点导航栏「题库」，可按标题搜索；列表会标明每题的时限、内存和类型（标准 / 特判 / 交互）。
2. 点进题目：左侧是题面（支持 Markdown、LaTeX 公式和代码高亮）与样例，右侧是「提交代码」卡片。
3. 选择语言，在编辑器里写代码（或直接粘贴），点「提交」。
4. 下方会出现「最近提交」实时卡片，全程**无需刷新页面**：状态从 **排队中 / 编译中 / 评测中**（旋转图标，评测中还会显示 `已判/总数` 进度）自动推进到最终结果；判题过程中下方一排**测试点圆点**随判题逐个点亮（绿 ✓ 通过 / 红 ✗ 失败 / 灰色待测），一眼看到判到第几个点。出结果时以**完整判定名**大字展示（如 `Accepted`、`Wrong Answer`），并给出耗时 / 内存 / 得分（IOI 题）统计。比赛题页面提交后同样有这张卡片。

> 站内列表、榜单与详情页使用短代码（AC / WA / TLE…）；只有这张实时卡片用完整判定名：AC=Accepted、WA=Wrong Answer、TLE=Time Limit Exceeded、MLE=Memory Limit Exceeded、RE=Runtime Error、CE=Compile Error、SE=System Error。

语言与资源档位（题目的时限/内存按此放宽）：

| 语言 | 时限倍率 | 内存放宽 | 说明 |
|---|---|---|---|
| C++ 17 (g++) | 1× | +8 MB | `g++ -O2 -std=c++17` |
| Python 3 | 4× | +128 MB | 解释执行，启动开销已计入倍率 |
| Java 17 | 3× | +512 MB | JVM 堆栈参数已配好 |

判定结果含义：

| 状态 | 含义 |
|---|---|
| AC | 通过 |
| WA | 答案错误（与标准输出比对失败，或被特判判错） |
| TLE | 超出时限（含语言倍率后仍超时） |
| MLE | 超出内存（含语言放宽后仍超限） |
| RE | 运行时错误（崩溃、非零退出码） |
| CE | 编译错误（提交详情里能看到编译器报错） |
| SE | 判题系统错误（不是你的问题，找管理员） |
| PENDING / COMPILING / JUDGING | 排队中 / 编译中 / 判题中，稍等 |
| SKIPPED | 该测试点被跳过，见下 |

**首败即停**：比赛进行中的提交一旦某个测试点不通过，后面的测试点直接标记 `SKIPPED` 不再运行——比赛里你只需要知道过没过，这样也把判题资源让给其他选手。平时在题库的提交始终跑完全部测试点，方便你定位具体挂在哪里。

在「提交记录」页可以勾选「只看我的」、按状态筛选，点任意一行可回看代码和逐测试点详情。若打开时提交还在判题中，详情页会**自动跟进**到出结果（逐测试点表格随结果刷新），同样无需手动刷新。每人每分钟最多提交 15 次。

## 我想看题解、写题解

题目页下方是「题解区」。**对这道题提交过一次（任意结果）后才能查看和发帖**；比赛进行中的赛题题解全区锁定，比赛结束自动开放。

点「写题解」发帖：标题可选，正文用所见即所得编辑器，支持加粗、标题、代码块、图片、链接。每层楼都可以「回复」；题目作者和管理员发的「官方题解」带绿色标识置顶。

## 我想按题单训练

1. 点导航栏「题单」，浏览全站公开的训练列表。
2. 点进题单：每道题右侧自动显示你的进度——**未做 / 尝试过 / 已 AC**，点题目名直接跳去刷题。
3. 如果你在某个小组里，小组页还有队长共享的题单（见下文「我想管理训练小组」）。

## 我想参加一场比赛

1. 点导航栏「比赛」，列表里有每场的状态：未开始 / 进行中 / 已结束。
2. 点进比赛页，顶部有倒计时和公告（比赛期间请留意公告，数据更新、重测等都会在这里通知）。
3. **先报名再提交**：在「报名参赛」卡片填队伍名（可选），选择「正式队伍」或「打星队（不占名次）」，点「报名」。报名后可以改队名（改完回车保存），也可以「取消报名」。未报名就无法在比赛内提交（赛后补题不受此限）。
4. 在「题目」标签点题进入作答。**赛题是本场比赛的独立副本，必须从比赛页点进去提交才会计入榜单**；在题库里找到同名题提交是不算的。

### 读懂榜单

「榜单」标签实时刷新。格子和列的含义按赛制分两种：

- **ACM 赛制**：按解题数排名，相同解题数比罚时（分钟）。格子里绿色 = 已通过（`+分钟数`），红色 = 失败次数（`-N`）。
- **IOI 赛制**：按总分排名，没有罚时概念；每题取你所有提交里的最高得分（按测试点给部分分），格子里直接显示分数。

图例说明：`★ 打星不占名次`（打星队参与排名计算但不占位，名次列显示 ★），红名 = 被裁判标记作弊。

**封榜**：比赛后段榜单会冻结，顶部出现「榜单已冻结」标识。封榜后的新提交在格子上只显示黄色的 `?N`（表示有 N 条待揭晓的提交），不显示判定结果；比赛结束后自动解封并结算。

页面上还有「导出榜单 CSV」和「投屏模式」（在大屏幕上全屏滚动展示榜单）两个按钮。

比赛页的「提交记录」标签汇总本场全部提交；封榜期间这里同样会遮蔽判定结果，只能看到有待判提交。

### 比赛结束后：补题模式

比赛一结束就进入补题模式：顶部显示「已结束 · 补题模式」，题目页带「补题」徽章。此时任何人都可以继续提交这些题，但**不再影响榜单**；题解区同时开放，适合赛后复盘。

## 我想打组队赛（ICPC 三人一队）

比赛开启组队模式时，报名卡片变成「组队报名（ICPC 三人一队）」：

1. 先在「小组」页建好队、拉齐队员（见下一节），确保你是**队长**。
2. 回到比赛页，在下拉框里选择你担任队长的小组，选「正式队伍」或「打星队」，点「以队报名」。
3. 之后**任一队员的提交都计入本队成绩**，榜单按队伍聚合显示。

下拉框为空说明你还没有担任队长的小组，先去「小组」页创建。

## 我想创建或管理训练小组

**加入小组**：在「小组」页右上角的输入框填邀请码，点「加入」。邀请码向队长要。

**创建小组**：点「创建小组」，填名称、简介和人数上限（1–5 人，ICPC 队为 3 人）。创建者即队长。

小组详情页包含四块：成员列表、共享题单、队内公告、**队内排行**（按组内共享题单的去重 AC 数排序）。队长的管理操作都在这个页面：

- 成员管理：按用户名直接拉人、移除成员、转让队长；
- 邀请码：展示当前邀请码，可一键重置（旧码立即失效）；
- 公告：发布/删除队内公告；
- 共享题单：把自己的题单共享给全组，可随时取消共享。

任何成员都可以「退出小组」；注意**队长退出会直接解散小组**。

## 我想看我的刷题数据

点导航栏「个人中心」（在榜单、题解区点任何人的用户名也能看到他的主页）：

- 顶部统计：已解决题目、尝试题目、AC 率；
- **近一年活跃度**热力图：本站数据始终包含，勾选「合并平台」可以把已绑定的外部平台刷题记录叠加进来；
- 近 30 天趋势（提交/AC 曲线）、提交状态分布饼图、标签强弱分布（按尝试排序）、提交状态明细。

## 我想绑定 Codeforces / 洛谷等外部账号

绑定与统计都已整合进「个人中心」：

1. 打开「个人中心」，找到「外站 OJ 刷题数据」卡片。
2. 选择平台（Codeforces / 洛谷 / AtCoder / 牛客），填写账号——洛谷填用户名，牛客填数字 ID 或主页链接——点「绑定并立即同步」。
3. 绑定后系统**每小时自动增量同步一次**（只读取公开数据）；绑定列表里随时可点「立即同步」手动刷新，或「解绑」（已同步的历史记录会保留）。
4. 同一张卡片下方就是合并报表：各平台的提交 / AC / 已解决统计徽章、跨平台最近 AC 列表；再勾选上方热力图的「合并平台」，外站记录就会叠加进热力图。

洛谷、牛客反爬较强，同步失败时状态列会显示原因，稍后重试即可。

## 我想导入一道外站题目

除了从零出题，你还可以把外站 OJ 的公开题目一键导入本站练习：

1. 打开「个人中心」的「导入外站题目」卡片，选择平台（目前内置 Codeforces、洛谷），填题号（如 `1900A` / `P1001`），先「预览题面」核对，再点「导入」。
2. 导入内容 = 题面 + 公开样例；**测试数据不会被抓取**。这类题会带「待补测试数据」标记，在出题人 / 管理员补齐数据之前无法正常评测。
3. 一般用户导入的题与自建题一样**进入审核**：通过前隐藏、通过后进入公开题库；出题人及以上导入则直接进入正式题库。

题面质量说明：Codeforces 导入包含完整题面（输入 / 输出说明、样例代码块，公式可正常渲染）；洛谷受平台反爬影响可能暂时失败，稍后重试。

## 我想出一道题

1. 在地址栏打开「站点地址 + `/my/problems`」，进入「我的题目」页，点「新建题目」。
2. 在全页编辑器里填写：标题、题面（所见即所得，右侧实时预览）、输入/输出描述、提示（可选）、时限、内存、判题模式（标准比对 / SPJ 特判 / 交互题）。
3. 点「保存并提交审核」。题目状态流转：**待审核 → 已通过 / 已驳回（可修改重投）**。
4. 审核通过前题目只有你自己可见、不计入公开题库；测试数据与样例在审核通过后由管理员协助配置。被驳回的题可以编辑后重新提交，也可以在列表上直接点「重投」。

## 常见问题

| 现象 | 处理 |
|---|---|
| 提交一直 PENDING | 判题机可能在忙（多人同时提交），稍等；持续超过 5 分钟找管理员 |
| 比赛格子上是 `?3` 不显示结果 | 封榜中，`?N` 表示封榜后有 N 条提交待揭晓，赛后自动解封 |
| 比赛里提交被拦、提示需要报名 | 报名制比赛必须先在比赛页报名；赛后补题不受此限 |
| 交互题怎么写 | 程序的 stdin/stdout 直连判题机的交互器，读到什么答什么，注意每轮输出后刷新缓冲；详见《SPJ 与交互题约定》 |
| 注册邀请码失效 | 邀请码有次数/有效期限制，找管理员要新的 |
| 登录提示请求过于频繁 | 触发了限流（登录每分钟 10 次），稍等再试 |
| 绑定洛谷/牛客后同步失败 | 对方平台反爬较强，稍后在个人中心「外站 OJ 刷题数据」卡里点「立即同步」重试 |
| 导入的外站题不能正常评测 | 外站导入只含题面与公开样例，题目标「待补测试数据」；等出题人/管理员补齐数据 |
| 提交后要刷新才能看到结果吗 | 不需要——题目页、比赛题页与提交详情页都会自动跟进到出结果 |
| 网页打不开 | 可能是网络或服务器维护，找管理员 |
